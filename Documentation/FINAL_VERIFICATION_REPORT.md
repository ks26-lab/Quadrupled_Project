## 4. 3D Simulation Mechanics & Contact Behavior

| Feature / Behavior | Implementation Detail | Audit Finding |
| :--- | :--- | :--- |
| **Conveyor Motion** | Stance velocity subtraction: $v_{\text{robot, world}} = (v_{\text{gait}} - v_{\text{belt}}) \cdot (\bar{s}_{\text{stance}} > 0.25)$ | **Physically Consistent**: Robot walks in place relative to the world when $v_{\text{gait}} = v_{\text{belt}} = 0.10\,\text{m/s}$. |
| **Obstacle Collision** | AABB check against obstacle bounding boxes; terrain height $z_{\text{terrain}}$ is elevated to obstacle height ($+0.04\,\text{m}$ or $+0.08\,\text{m}$). | **Kinematic Detection**: Correctly elevates stance contact surface; not a 3D penalty mesh physics engine. |
| **Contact Mechanics** | Normal contact force $F_N = \max(0, 1500 \cdot \Delta z + 50)\,\text{N}$. | **Spring-Damper Contact**: Yields realistic contact forces and stance phase grounding. |
| **Pitch Disturbances** | Differential elevation induces pitching moment: $\tau_{\text{terrain}} = -15.0 \cdot (h_{\text{front}} - h_{\text{rear}})\,\text{N}\cdot\text{m}$. | **Closed-Loop Balance**: Front obstacle elevates front feet, generating pitching torque that the controller suppresses. |
| **Contact Loss Fault** | RF leg contact forced to zero at $t = 3.0\,\text{s}$ ($F_N = 0$). | **Fault Recovery**: Induces asymmetric roll/pitch disturbance that tests robustness. |
