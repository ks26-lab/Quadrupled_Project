# Quadruped Robot Body-Pitch Control Project

This repository contains the reorganized MATLAB project for the **Quadruped Robot Body-Pitch Control Project**.

## Quick Start
To initialize the project and add all paths:
```matlab
project_setup
```

To run the interactive project launcher:
```matlab
run_project
```

To run individual phases directly:
```matlab
run_phase_1      % Physical Model & Initial Response
run_phase_2      % SISO Plant & Open-Loop Analysis
run_phase_3      % Proportional Feedback Controller
run_phase_4      % PI Controller Design & Pareto Tuning
run_phase_4_5    % Disturbance Rejection Validation
```
