# Project Documentation

This directory contains reference documentation, academic literature, and architectural reports for the Quadruped Robot Body-Pitch Control Project.

## Documents
- **`dependency_map.md`**: Complete cross-phase dependency breakdown, input/output specifications, and data flow.
- **`project_structure_report.md`**: Audit report, directory restructuring details, and safety audit.
- **`QUADRUPED-ROBOT-GAIT-and-BALANCE-CONTROL (1).pdf`**: Background paper on quadrupedal robotic gait generation, attitude control, and balance stabilization.
