# Results Figures Directory

Stores output figures (`.fig`, `.png`, `.pdf`, `.eps`) generated by phase executions:
- Phase 1: Open-loop step and initial condition response plots
- Phase 2: Pole-zero maps and open-loop impulse response plots
- Phase 3: Systematic $K_p$ parameter sweeps, Pareto trade-off, and disturbance response plots
- Phase 4: 3D Pareto front scatter and PI candidate comparison step responses
- Phase 4.5: Sustained and transient torque disturbance rejection response plots
